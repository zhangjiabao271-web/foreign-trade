# 线索工作台

沿用现有工作台视觉与生成 API 客户端。身份与组织切换由根 AuthGate 管理，
真实会话不要求用户粘贴令牌；组件内连接面板仅供显式隔离测试路径。

操作入口使用当前会话范围的 `/me/context`：创建、状态推进检查 `lead.write`，
转换独立检查 `lead.convert`。权限未确认或查询失败时不显示写入口；失去写权限时
卸载已打开的创建表单。只读空列表不提示登记。后端路由和领域服务仍独立授权，
这些界面条件不代替服务器安全检查。

备注、来源和活动正文遵循 ADR-020，审核仍使用独立 WorkTextReview。
测试覆盖授权创建、只读 NEW/RESPONDED、权限等待/失败、转换权限独立性及会话降权。
