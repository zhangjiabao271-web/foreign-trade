# Manual export workspace

Customs/refund lists, details, manual fact commands and evidence share generated contracts.
Forms use RHF/Zod. Financial amounts remain decimal strings; server commands enforce rules.
No government submission occurs. Current server permissions control actions, with backend
authorization authoritative. Creation retains its idempotency key until successful navigation.

Pending current evidence uses the shared exact-file resume control after reload. Existing
write/finality gates remain in force, and successful recovery refreshes export/overview facts.

Source notes/rejection reasons have an explicit confidential state and a separate shared reviewer.
CaseKind refunds maps explicitly to the generated source-review kind refund. Original export.read
and profit.read are required; this does not grant export.write or reopen finalized cases. Receipt
identifiers remain visible; source review does not release historical timeline entries.
