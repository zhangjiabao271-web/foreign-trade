# Copilot workspace

Use generated API contracts and session-scoped queries. Explicit intent and source selection
replace unrestricted chat input. Source facts, inferences and drafts are separately labelled.
Provider errors never masquerade as successful model output. Task approval is a separate,
reason-required human action; this page cannot send mail or change commercial/financial state.

Reuse the existing navy/teal operational ledger design and RHF/Zod forms. Model capability and
permission checks remain server-owned. Responsive and keyboard acceptance is required.

The separate content-review queue only lists explicitly submitted draft candidates. Submission
requires an affirmative checkbox. Reviewers inspect all artifact fields; editing saves a new
pending candidate, never approves it implicitly or changes the original. Decision controls bind
the displayed candidate version/digest. Retry retains the exact failed command and key.
Original input/tool prose/provider cost stay protected for sales/operations even after draft
release. Task execution remains separately reasoned and binds the released ID/version.
Use generated nullable response fields; never infer that protected values are empty facts.
