# Failed event administration

Organization-scoped DEAD event list; no payload or raw infrastructure errors are shown.
Read/replay permissions are checked independently. Human replay requires a reason,
explicit confirmation and the displayed optimistic version. Requeue success is not
consumer completion. Pagination is offset-based, matching Overview; refresh after
concurrent changes. Session-scoped query caches reset when the identity changes.

`/admin/operations` adds a read-only, ADMIN-gated operational view using generated contracts.
It separates persisted status counts from bounded process-local timing samples and unknown AI
costs from known estimates. Loading/error/no-permission states do not show fake zero totals.
Existing workbench typography and colors are retained; the UI skills' marketing suggestions
do not override the project's internal operations context.
