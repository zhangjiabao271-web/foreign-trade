# Order contracts

0029 protects notes and nested snapshot descriptions/terms independently of the order or signed
file. Protected fields show explicit labels, and finalized contracts remain disclosure-reviewable.
An unavailable original note is disabled and omitted from a draft update, not submitted as null;
the backend preserves omitted fields. Party names and external numbers remain identifiers under
the original permissions, with internal cost/profit entry prohibited. Existing values, signature
evidence and money never change as a side effect of disclosure review.

Order-linked contract snapshots and exact signed file versions follow ADR-015. The panel reuses
the existing ledger tokens and document transfer operation. RHF/Zod forms hold their opening
version; unchanged failed commands keep their key. No price, order-state or legal signature is
performed by the browser. Manager signature registration requires explicit confirmation.
Signed/voided facts are read-only; upload success is not scan acceptance. Contract reads exclude
internal product cost/profit. Every query key includes the current session scope and order.

Pending evidence exposes the shared original-file resume control only on active orders to
document writers. It reuses persisted version identity after reload and refreshes contract
evidence; signing still requires an AVAILABLE immutable storage version.
