# ADR-018：当前组织设置与显式成员授权

状态：已接受。日期：2026-09-06。

## 决策

- 仅 ADMIN 可以读取和修改当前组织设置、读取成员以及执行成员授权命令。组织设置限名称、IANA 时区；不提供组织创建、删除或停用。
- 管理员核实已有 Logto 用户的准确 subject 后，显式建立本地 ACTIVE membership。初次映射允许填写展示名；已存在的全局 User 不得被组织管理员修改。此操作不是创建登录账号、发送邀请或设置密码；登录仍须通过真实 issuer 的 JWT 验证。禁用或删除的全局用户不能通过本命令恢复。
- 成员角色变更、停用、重新启用使用独立命令；不删除成员或历史事实。成员列表只返回当前组织关联的数据，不提供全局用户搜索或其他组织成员信息。
- 所有管理命令先锁定当前 organization，再从数据库重新核验操作者仍是有效 ADMIN，之后取得幂等键并处理目标。所有同组织管理写入遵守此锁顺序，避免并发降级导致组织没有有效管理员。
- 禁止停用或降级最后一位有效管理员。有效指 ACTIVE、未删除 membership 且对应 User 为 ACTIVE、未删除。允许有其他有效管理员时自我降级或停用；后续请求重新执行认证，不承诺撤销已开始的普通业务请求。
- 修改须携带理由、目标版本和幂等键；初次添加无需目标版本。业务写入、activity、audit 和仅含 ID 的 outbox 在同一事务提交。组织时区仅影响未来业务日期计算，不改写 UTC 历史时间。
- 分页使用组织内 created_at/id 游标，默认 20、最多 100；新增组织/创建时间/id 索引。组织初始化继续使用运维 bootstrap，远程 Logto 账号管理不在本模块实现。

## 验收与风险

必须验证跨组织目标和游标、非管理员拒绝、陈旧管理员上下文、最后管理员并发竞争、全局用户字段保持不变、重复命令及事务证据失败回滚。真实 Logto 账号创建、登录和退出属于独立集成验收，不能由本地授权 fixture 替代。
