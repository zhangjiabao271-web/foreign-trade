# ADR-019：隔离且不泄密的运行观测

状态：已接受。日期：2026-09-06。

## 决策

实施指南第 14 节要求的日志与监控不是业务事实源，不得替代审计、outbox 或数据库状态。

- API/Worker 输出结构化 JSON，采用固定事件及字段白名单。关联使用 request_id/correlation_id；组织编号只来自已认证请求上下文或验证后的任务上下文。不记录请求头、正文、查询参数、原始路径值、JWT、密码、存储签名 URL、SQL 参数或原始异常消息。第三方日志也经过安全格式化；诊断保留严重级别，原始消息不透传。
- API latency/error 以固定路由模板统计。临时计数采用有界进程内缓存，明确统计起点、样本数与重启/驱逐限制；不承诺跨进程或历史汇总。未经认证的请求只进入内部运行日志，不归因于客户端自行声明的组织。
- 连接池数值仅供运维日志使用，不能在组织业务接口泄露共享服务的其他租户负载。任务日志只记录固定任务名、合法追踪 ID、结果类别及耗时；不记录参数、返回正文或原始异常。
- 组织运行概览使用新增明确权限，仅 ADMIN 授权。API 和查询层重复检查，所有业务统计限定 organization_id。以 PostgreSQL 计算 outbox backlog/dead、未确认消费积压/最老年龄、job failure、文件待上传/扫描/拒绝、AI tokens/已知估算成本/未知成本数及人工批准率。
- 批准率定义为 APPROVED / (APPROVED + REJECTED)，没有已决请求时返回 null；未知 AI 成本不能按零费用解释。文件 REJECTED 不等同于检测到恶意软件，待上传老化不等同于确认上传失败。上传接口错误指标与数据库文件状态分别展示。
- 运行概览只读，不写审计或递归 outbox；业务修复继续使用已有受控命令。监控采集失败不得回滚已提交业务，也不得改变请求或任务的重试语义。新增索引只服务组织内统计，不回填或删除事实。

## 验收

注入头部/查询/正文/异常秘密，确认应用和第三方输出不包含原值；验证追踪关联、缓存容量、重启窗口含义、并发计数。真实 PostgreSQL 验证两组织精确计数、权限和 null 成本/批准率，浏览器验证无权限不请求数据和空/错/加载状态。容器验证 API/Worker 日志为安全 JSON、健康与原有商业主链不回归。真实模型服务和生产恶意扫描不由此替代。
