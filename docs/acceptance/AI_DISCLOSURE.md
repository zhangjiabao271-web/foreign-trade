# 私有 AI 草稿内容审核验收

2026-09-07，依据用户明确确认及 ADR-026。此记录不替代 V1 总验收。

## 已实现的边界

- 创建者主动提交指定成功草稿；未提交运行及其工具调用仍只允许原创建者在现有权限内访问。
- 本组织管理员、经理、财务凭原始业务读取权限审核已提交候选；不新增财务的任务执行审批权。
- 销售、运营作为创建者也不能读取未经审核的生成正文、原始输入、工具正文或模型费用。
- 审核展示并绑定候选全部 artifact：推断、草稿、任务标题。脱敏追加待审版本，保留原稿和旧候选；必须再次明确确认才开放。
- 只向原创建者开放最新且内容未变化的已审核候选，不自动向其他同事公开。不附带开放原始事实 JSON、来源正文、工具记录、其他附件或任务审批副本。
- 运行/候选变化、新版本及撤回开放均使旧发布失效；历史分页不能再次开放旧版本。已经保存的外部副本无法召回。
- 内容审核不发消息、不改价、不创建任务。任务执行申请是独立动作，销售需提交其所见开放候选的 ID 和版本，避免后台变化后静默执行另一份标题。

## 操作说明

在“受控业务助手”选择自己的成功记录，勾选并点击“提交内容审核”。审核人在“草稿内容审核 · 不执行业务”核对候选；必要时保存脱敏新候选，再单独记录内容决定。业务任务仍在独立任务审批区处理。

原始私有记录和模型费用没有因此全局开放。该机制依赖审核人真实核对内容，不宣称自动识别所有成本，也不保证模型质量。真实身份初始化、初始化后的身份恢复、模型/扫描生产配置等仍不由本切片关闭。
